## 3. 화면과 동작
3-1. 추가한 영화 목록

위치 및 구성

검색창 아래에 추가한 영화를 가로 한 줄로 표시한다.
각 항목은 TMDB에서 가져온 포스터와 제목으로 이루어진 카드이다.

동작

검색 결과에서 [목록에 추가]를 누르면 이 목록에 나타난다.
목록의 카드를 드래그해서 S / A / B / C / D 티어 행에 놓으면 해당 등급으로 배정되고, 목록에서 사라진다.
목록이 한 줄에 다 보이지 않으면 양쪽 끝에 ◀ 더보기 / 더보기 ▶ 버튼을 두고, 누를 때마다 목록을 가로로 넘긴다. 더 넘길 방향이 없으면 해당 버튼은 비활성화된다.
목록이 비어 있으면 "검색으로 영화를 추가해 보세요"라는 안내를 표시한다.

티어 카드 조작

티어에 배정된 카드는 다른 티어로 드래그해서 등급을 바꿀 수 있다.
카드를 누르면 등급 변경 또는 삭제 메뉴가 열린다.

예외 처리

포스터를 가져오지 못한 영화는 제목만 표시되는 기본 카드로 보여 준다.
같은 제목의 영화는 목록과 티어 어디에서도 중복 추가되지 않고, "이미 추가된 영화입니다" 안내를 표시한다.

3-2. 포스터 표시
포스터는 검색 결과와 목록, 티어 카드에 TMDB 이미지 서버에서 직접 불러와 표시한다.
포스터를 가져오지 못한 영화는 제목이 적힌 회색 기본 카드로 대체한다.
키를 저장하면 포스터가 없는 기본 목록 영화도 자동으로 포스터를 채운다.

 이미지 저장 제한 
PNG 저장은 화면에 보이는 티어리스트 영역만 담는다. 추가한 영화 목록은 포함하지 않는다.
포스터는 웹 보안 정책에 따라 PNG에 빠질 수 있으며, 이 경우 제목 카드 형태로 저장될 수 있다.
이미지 저장은 인터넷 연결이 필요하다(html2canvas를 CDN에서 불러옴).

├─────────────────────────────┤

### 티어 구조 및 색상
- 등급 차이는 **피라미드 형태(칸 너비)** 로 표현
- 티어 행 배경색은 **노란색 계열 단일 색상**, 위로 갈수록 밝고 아래로 갈수록 진함

| 티어 | 방향 | 배경색 |
|------|------|--------|
| S | 최상위 | 🟡 가장 밝은 노랑 |
| A | ↑ | 🟡 밝은 노랑 |
| B | 중간 | 🟡 중간 노랑 |
| C | ↓ | 🟡 진한 노랑 |
| D | 최하위 | 🟡 가장 진한 노랑 |

```
        [ S ]          ← 가장 밝은 노랑 (#FFFDE7)
      [ A ][ A ]       ← 밝은 노랑    (#FFF176)
    [ B ][ B ][ B ]    ← 중간 노랑   (#FFEE58)
  [ C ][ C ][ C ][ C ] ← 진한 노랑  (#FDD835)
[ D ][ D ][ D ][ D ][ D ] ← 가장 진한 노랑 (#F9A825)
```



### 동작 목록
동작	설명
영화 검색	제목 입력 → 포스터+제목 검색 결과 표시
목록 추가	검색 결과에서 [목록에 추가] → 추가한 영화 목록에 표시
티어 배정	목록 카드를 티어 행으로 드래그 → 목록에서 사라지고 티어에 표시
등급 변경	티어 카드를 다른 티어로 드래그 앤 드롭
목록 넘기기	양쪽 더보기 버튼으로 가로 스크롤
카드 삭제	카드를 눌러 메뉴에서 삭제

참고: 기존 "티어 배정: 검색 결과에서 티어 선택 후 추가" 방식은 이 내용으로 대체됩니다.



###  영화 검색 및 카드 생성
- **입력 검증**: 빈칸이나 공백만 입력하고 검색할 경우, 카드를 생성하지 않고 "영화 제목을 입력해주세요"라는 안내 문구 노출
- **카드 생성**: 유효한 제목 입력 시 TMDB API를 통해 영화 정보를 가져와 포스터와 제목이 포함된 카드 생성 
- **카드 중복**: 같은 제목은 중복 안내 문구 노출 
- **디자인**: 장르별 테두리 색상 구분 없이 깔끔한 기본 카드 디자인 적용
- **더보기 버튼**: 영화를 많이 추가 한 경우 양 쪽으로 더 보기 버튼 적용
# 환경 및 호환성
- **단일 파일 실행**: 외부 라이브러리 링크를 최소화하거나 CDN을 활용하여, HTML 파일 하나만 실행하면 즉시 작동
- **반응형 웹**: 모바일이나 좁은 브라우저 창에서도 오른쪽 화면이 잘리지 않고 모든 콘텐츠 확인 가능


### 데이터 저장
- 변경 시 **localStorage 자동 저장**
- **JSON 파일**로 저장
- API 키는 저장 파일 및 HTML 코드에 **포함하지 않음**
2-1. 설정 및 API 키 (추가)
API 키는 TMDB의 “API 키(v3)” 를 사용한다. “API 읽기 접근 토큰(v4, eyJ로 시작)”은 사용하지 않는다.
설정 화면에서 키를 입력하면 이 브라우저의 localStorage에만 저장된다.
키가 없거나 잘못된 경우 검색창 아래에 원인을 안내하는 문구를 표시한다.
키 미입력: "먼저 ⚙️ 설정에서 TMDB API 키를 입력해주세요."
인증 실패(401): TMDB가 보낸 상세 메시지와 함께 "설정에는 ‘API 키(v3)’를 입력해 주세요" 안내
네트워크 오류: "네트워크 오류가 발생했습니다. 인터넷 연결을 확인해주세요."
### 불러오기 안전장치 3단계
```
1단계: "백업 후 불러오기" / "그냥 불러오기" / "취소"
2단계: 백업 선택 시 → 현재 데이터 JSON 자동 저장
3단계: "현재 목록이 교체됩니다. 계속하시겠습니까?" → 확인 / 취소
```

포스터는 웹 보안 정책에 따라 PNG에 빠질 수 있으며, 이 경우 제목 카드 형태로 저장될 수 있다.
