## 비교할 때 확인한 행동

1. 기본 영화 `기생충`을 추가한 영화 목록에서 S등급으로 옮깁니다.
2. S등급에 놓인 영화를 다시 추가한 영화 목록으로 되돌립니다.
3. `미션1_기록.md`에는 첫 번째 동작은 두 AI 모두 성공했고, 두 번째 동작은 ChatGPT 초안에서만 성공했다고 기록되어 있습니다.
4. 이후 포스터가 PNG 저장에서 누락되는 문제와 초기 영화 제목 `내 머리 속의 지우개` 표기를 수정한 내용도 기록되어 있습니다.

이 항목들은 **당시 작성한 검증 기록의 요약**이며, 이번 README 작성 과정에서 초안들의 동작을 새로 테스트했다는 뜻은 아닙니다.

HTML 파일은 내려받아 브라우저에서 직접 열어 확인하세요. GitHub 화면에서는 실행 화면 대신 HTML 소스가 보일 수 있습니다.

> 다른 미션의 HTML과 내용이 같거나 다를 수 있습니다. 파일의 작성 목적과 시점을 기준으로 비교하며, 여기 있는 초안과 기존 기록을 덮어쓰지 않습니다.
