#잘된 점

1. 영화 8개가 처음부터 준비되어 있어 사용자가 바로 등급을 나눌 수 있도록 만들어져 있다.
2. S·A·B·C 등급이 색깔별로 구분되어 있어 한눈에 알아보기 쉽다.
3. 영화 카드를 선택하고 등급 버튼을 누르거나 드래그해서 옮기는 두 가지 방법이 구현되어 있다.
4. 영화를 추가할 수 있고, '처음으로' 버튼을 누르면 초기 영화 8개로 돌아가도록 만들어져 있다.
5. 별도의 로그인이나 외부 파일 없이 HTML 파일 하나로 실행할 수 있도록 구성되어 있다.


#고치면 좋을 점

1. 영화와 등급이 브라우저의 저장되지 않는 문제
 |본것|기준|제안|
|---|---|---|
|[새로운 영화를 추가하거나 기존 영화의 등급을 변경 후 브라우저 새로고침 ]을 했더니 [이전 내용이 저장되지 않고 처음으로 돌아가도록 되어 있다.] | 기획서의 ['같은 브라우저에서 같은 파일을 다시 열어도 영화와 등급이 남는다'는 완성 기준.]|[브라우저의 localStorage 저장 기능을 추가해 영화를 추가하거나 등급을 변경할 때 브라우저에 자동으로 저장되면 좋겠다.]|

 |본것|기준|제안|

3. 영화 제목을 입력하지 않아도 카드가 추가되는 문제
 |본것|기준|제안|
|---|---|---|

4. 이미 추가한 영화의 제목을 수정하거나 삭제할 수 없는 점

5. '처음으로' 버튼을 실수로 누르면 기록이 사라지는 문제
