## 자료 확인 순서

1. [미션3_기록.md](./미션3_기록.md)에서 AI·동료의 각 의견과 직접 확인 결과, 반영·보류·되묻기 결정을 확인합니다.
2. [검증캡쳐자료.md](./검증캡쳐자료.md)에서 실제 화면 사진과 기획서·화면 비교 설명을 확인합니다.
3. [피드백.md](./피드백.md)에서 민수 님께 전달할 장점과 개선 제안을 확인합니다.

## 제출 파일과 제공 자료의 구분

- **필수 제출 파일:** `미션3_기록.md`, `피드백.md`
- **함께 정리한 검증 자료:** `검증캡쳐자료.md`, `검증캡쳐자료원본/`의 이미지 2장
- **미션에서 제공한 샘플:** `민수_기획서.md`, `민수_영화티어리스트.html`, `받은_피드백.md` — 검토에 사용하는 자료이며 필수 제출 파일은 아닙니다.

캡처 자료는 압축파일 대신 Markdown 문서와 이미지 원본 폴더로 정리했습니다. 기존 `미션3_기록.md`와 `피드백.md`의 본문은 변경하지 않았습니다.
