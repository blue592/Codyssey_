# 🎬 나만의 영화 티어리스트
코디세이 미션을 진행하며 만드는 개인용 영화 티어리스트 웹페이지입니다.

내가 본 영화를 S / A / B / C / D 등급으로 정리하고, 영화 카드의 위치를 바꾸며 나만의 평가를 기록하는 것을 목표로 합니다. 이 저장소에는 기획서부터 AI별 초안, 비교 결과, 수정 과정까지 프로젝트의 학습 기록을 모읍니다.

## 기획한 주요 기능

아래 내용은 [미션 1-1 기획서](미션%201-1/기획서.md)를 기준으로 정리한 기능입니다. 버전별 동작 차이와 직접 확인한 결과는 [미션 기록](미션%201-1/미션1_기록.md)에서 확인할 수 있습니다.

| 기능 | 설명 |
|---|---|
| 영화 검색과 추가 | TMDB API로 영화 제목을 검색하고 포스터와 함께 목록에 추가 |
| 등급 분류 | 추가한 영화를 S / A / B / C / D 티어로 드래그하여 배정 |
| 등급 변경과 삭제 | 영화 카드를 다른 티어로 옮기거나 삭제 |
| 자동 저장 | 현재 브라우저의 localStorage에 변경 내용 저장 |
| 데이터 백업 | JSON 파일로 저장하고 불러오기 |
| 이미지 저장 | 티어리스트 영역을 PNG 이미지로 저장 |
| 화면 구성 | 노란색 계열의 피라미드형 티어와 반응형 화면 |

## 실행 방법

1. 저장소 상단의 **Code → Download ZIP**으로 파일을 내려받습니다.
2. 압축을 풀고 **미션 1-1** 폴더를 엽니다.
3. **영화티어리스트수정본.html**을 브라우저로 엽니다.
4. AI별 초안을 비교하려면 각 초안 HTML 파일을 별도로 엽니다.

HTML·CSS·JavaScript를 HTML 파일 하나에 담는 방식으로 기획했습니다. 별도의 서버 설치 없이 브라우저에서 열 수 있지만, TMDB 영화 검색·포스터와 외부 라이브러리를 사용하는 기능에는 인터넷 연결이 필요합니다. GitHub에서 HTML 파일 링크를 누르면 실행 화면 대신 소스 코드가 보일 수 있습니다.

## 저장 및 API 키 안내

- TMDB API를 사용하는 버전은 설정에서 본인의 API 키(v3)를 입력합니다.
- 기획상 API 키는 해당 브라우저의 localStorage에 보관하며, HTML 코드와 JSON 백업에는 포함하지 않습니다.
- localStorage의 기록은 다른 브라우저나 컴퓨터로 자동 동기화되지 않으므로, 옮길 때는 JSON 저장·불러오기를 사용합니다.
- 기획서에는 PNG 저장 시 외부 포스터가 누락될 수 있다는 제한이 기록되어 있습니다. 수정 과정과 확인 결과는 미션 기록을 참고해 주세요.

## 사용 기술과 학습 과정

**HTML · CSS · JavaScript · localStorage · TMDB API · html2canvas**

AI와의 질문·답변으로 요구사항을 정하고, 동일한 기획서로 만든 ChatGPT와 Claude의 결과물을 비교합니다. 직접 동작을 확인하며 선택한 이유와 수정 내용을 기록하고, 이후 미션의 결과물을 이어서 정리합니다.
