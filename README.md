# 🎬 나만의 영화 티어리스트

**내가 본 영화를 S · A · B · C · D 등급으로 정리하는 개인용 웹페이지**입니다. 영화 포스터를 보면서 카드를 옮기고, 목적에 따라 여러 개의 티어리스트를 따로 만들 수 있습니다.

별도의 프로그램이나 서버 설치 없이 **HTML 파일 하나를 브라우저에서 열어** 사용합니다.

> **미션 1-4의 실제 파일명:** [영화_원본.html](미션%201-4/영화_원본.html) (**기능 추가 전 원본**) · [영화_기능추가1.html](미션%201-4/영화_기능추가1.html) (**책갈피 기능을 추가한 1차 파일**) · [영화_기능추가수정1.html](미션%201-4/영화_기능추가수정1.html) (**저장·불러오기까지 수정한 파일**)
>
> **문서와 증거:** [기획서.md](미션%201-4/기획서.md) · [미션4_기록.md](미션%201-4/미션4_기록.md) · [대화캡쳐 및 실제검증 자료.md](미션%201-4/%EB%8C%80%ED%99%94%EC%BA%A1%EC%B3%90%20%EB%B0%8F%20%EC%8B%A4%EC%A0%9C%EA%B2%80%EC%A6%9D%20%EC%9E%90%EB%A3%8C.md)

**읽는 방법:** 이 README는 **저장소 전체의 안내**입니다. 아래 사용 방법은 실제 파일명 `영화_기능추가수정1.html`을 기준으로 설명합니다. 원본 `영화_원본.html`은 책갈피 기능을 더하기 전 상태이므로 수정하거나 덮어쓰지 않습니다. 다른 미션의 HTML도 각 작업 당시 상태를 보존한 별도 결과물입니다.

## 🚀 처음 사용하는 방법

1. 이 저장소의 초록색 **Code → Download ZIP**을 눌러 내려받습니다.
2. 압축을 풀고 **`미션 1-4`** 폴더를 엽니다.
3. **`영화_기능추가수정1.html`** 파일을 더블클릭해 브라우저에서 엽니다.
4. 처음에는 기본 영화 10편을 분류해 볼 수 있습니다. 새 영화를 검색하려면 **⚙️ 설정**에서 본인의 TMDB API 키(v3)를 입력합니다.
5. 영화 카드를 원하는 등급으로 끌어 놓거나 카드를 눌러 등급을 변경합니다.

**참고:** GitHub에서 `.html` 파일을 클릭하면 실행 화면 대신 코드가 보일 수 있습니다. 위 방법으로 파일을 내려받아 실행해 주세요.

## ✨ 주요 기능

| 기능 | 할 수 있는 일 |
|---|---|
| 🎞️ 영화 검색 | 제목을 검색해 TMDB의 영화 정보와 포스터를 보고 추가합니다. |
| 🏆 등급 분류 | 영화 카드를 **S / A / B / C / D** 중 원하는 칸으로 드래그합니다. |
| ✏️ 등급 변경·삭제 | 카드를 클릭해 다른 등급으로 옮기거나 목록에서 삭제합니다. |
| 📚 여러 책갈피 | `다시 보고 싶은 영화`, `가족 영화`처럼 제목을 정해 티어리스트를 여러 개 만듭니다. **책갈피마다 영화 목록과 등급을 따로 관리**합니다. |
| 💾 자동 저장 | 같은 브라우저에 변경 내용을 저장하고, 다시 열었을 때 불러옵니다. |
| 📁 JSON 저장·불러오기 | 현재 책갈피 하나 또는 전체 책갈피를 파일로 보관하고 복원합니다. |
| 🖼️ PNG 이미지 저장 | 현재 책갈피의 **등급표 영역**을 이미지로 저장합니다. |
| 📱 반응형 화면 | 컴퓨터와 좁은 화면에 맞게 배치가 조정됩니다. |

### 파일 저장과 불러오기

**파일 저장** 버튼을 누르면 다음 중 선택할 수 있습니다.

| 선택 | 결과 |
|---|---|
| 현재 책갈피만 저장 | 선택한 책갈피의 영화·등급을 JSON으로 저장 |
| 전체 책갈피 저장 | 모든 책갈피와 영화·등급을 하나의 JSON으로 저장 |

저장 파일 이름에는 **날짜와 책갈피 이름**이 들어갑니다.

**불러오기** 버튼을 누르면 다음 중 선택할 수 있습니다.

| 선택 | 결과 |
|---|---|
| 저장 후 불러오기 | 현재 기록을 먼저 백업하고 파일의 기록으로 교체 |
| 그냥 불러오기 | 백업 없이 파일의 기록으로 교체 (교체 전 확인) |
| 책갈피로 불러오기 | 기존 기록을 유지하고 새 책갈피로 추가 |

기록을 잃지 않도록 중요한 변경 전에는 **전체 책갈피 저장**으로 JSON 백업을 만들어 두는 것을 권장합니다.

## 🔐 데이터·API 키 안내

- **TMDB API 키(v3)**는 사용자 본인이 설정 화면에 입력합니다. 저장소의 HTML 코드나 JSON 백업 파일에는 키가 포함되지 않습니다.
- 영화 기록은 브라우저의 **localStorage**에 보관됩니다. 다른 컴퓨터·브라우저와 자동으로 동기화되지 않으므로 **JSON 저장·불러오기**를 사용해 옮겨 주세요.
- 검색·포스터 표시에는 인터넷 연결이 필요합니다. PNG 저장 시 외부 포스터를 불러오지 못하면 해당 영화는 **제목 카드**로 저장될 수 있습니다.
- PNG에는 **티어에 배정된 등급표**가 담기며, 아직 등급을 정하지 않은 영화 목록은 포함되지 않습니다.
