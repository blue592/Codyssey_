# 미션 1-2 — 오류를 좁혀 수정 전후 비교하기

영화 제목이 같더라도 **서로 다른 영화라면 각각 추가하고 등급을 지정할 수 있어야 한다**는 문제를 다룬 미션입니다. 수정 전 파일과 수정 후 파일을 별도로 보관합니다.

## 파일 안내

| 파일·폴더 | 역할 |
|---|---|
| [영화_수정전.html](./영화_수정전.html) | 문제를 재현한 수정 전 HTML. 미션 1-1의 `영화티어리스트수정본.html`과 코드 내용이 같음 |
| [영화_수정1.html](./영화_수정1.html) | 같은 제목의 다른 영화를 구분하도록 수정한 HTML |
| [미션_2_기록.md](./미션_2_기록.md) | 문제를 좁혀 적은 문장, AI 설명, 수정 후 확인 내용 |
| [실제검증내역.md](./실제검증내역.md) | 수정 전후 비교와 완성 기준별 실행 증거를 정리한 문서 |
| [대화내역.md](./대화내역.md) | 관련 AI 대화와 캡처 안내 |
| [자료원본](./자료원본/) | 실제검증내역과 대화내역에서 참조하는 PNG 이미지 원본 |

## 검증 포인트

1. 수정 전 파일에서 같은 제목·다른 포스터/개봉 연도의 영화 두 편을 검색·추가할 때 발생한 문제를 기록과 비교합니다.
2. 수정 후 파일에서는 영화 제목 하나만으로 중복을 판정하지 않고 **TMDB 고유 ID**를 우선 사용하도록 한 코드를 확인할 수 있습니다.
3. 수정 후 같은 제목의 서로 다른 영화를 각각 추가하고 등급으로 이동하는 결과는 [실제검증내역.md](./실제검증내역.md)와 [자료원본](./자료원본/)에서 확인합니다.
4. 기타 완성 기준 및 한계는 기록에 적힌 **직접 확인 결과**와 **코드·캡처만으로 확정할 수 없는 부분**을 구분해 읽습니다.

**주의:** 이 미션의 수정 대상은 `영화_수정1.html`입니다. `영화_수정전.html`은 비교용 원본으로 보존하며, 다른 미션의 HTML을 동일한 최신 버전으로 취급하지 않습니다.
