선택한 책갈피:

책갈피마다 영화 목록과 등급이 따로 저장됩니다. 새 책갈피에는 처음 영화 10편이 미분류로 들어갑니다.

추가한 영화 목록

변경 내용은 이 브라우저에 자동 저장됩니다. 중요한 기록은 파일로 보관해 주세요.
검색·포스터 로딩은 인터넷 연결이 필요합니다. API 키는 백업 파일에 포함되지 않습니다.
영화 정보 제공: TMDB · 이 서비스는 TMDB의 보증 또는 인증을 받지 않았습니다.

TMDB API 키 설정

본인의 API 키(v3)를 입력해 주세요. 키는 이 브라우저에만 저장되며 다른 기기로 자동 전달되지 않습니다.

공용 기기에서는 사용 후 키를 지워 주세요. 영화 기록 파일에는 키가 들어가지 않습니다.

파일 저장 방식 선택

어느 영화 기록을 저장할까요?

선택한 책갈피의 영화와 등급만 JSON 파일로 저장합니다.

모든 책갈피와 영화·등급을 한 파일에 저장합니다.

기록 불러오기

선택한 파일을 어떤 방식으로 불러올까요?

현재 전체 책갈피를 먼저 백업하고, 파일의 기록으로 교체합니다.

백업 없이 파일의 기록으로 교체합니다. 교체 전 확인합니다.

기존 책갈피는 유지하고, 파일의 기록을 새로운 책갈피로 추가합니다.
