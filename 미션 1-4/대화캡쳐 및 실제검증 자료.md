## 4. 기획서와 연결되는 확인 항목

| 관련 완성 기준 | 확인할 동작 | 이 문서에서 확인 가능한 증거 |
|---|---|---|
| 9번 — 여러 책갈피와 독립 등급 관리 | 이름이 다른 책갈피를 생성·전환하고 각 책갈피의 영화·등급이 독립적인지 확인 | 기능 요청 및 결과물 화면 캡처, HTML 소스 |
| 10번 — 파일 저장 범위 선택 | **파일 저장**을 눌러 현재 책갈피 또는 전체 책갈피를 선택할 수 있는지 확인 | 수정 요청 및 결과물 화면 캡처, HTML 소스 |
| 기존 1~8번 — 원래 기능 유지 | 영화 검색·이동·자동 저장·PNG·JSON·단일 HTML·반응형·빈 입력 차단 | 별도의 브라우저 실행 검증이 필요 |

> **검증 범위 주의:** 위 이미지 3장은 AI 대화와 수정 결과 화면의 증거입니다. 스크린샷만으로 기획서 완성 기준 10개를 전부 실행 검증했다고 단정하지 않습니다. 실제 브라우저에서 각각 확인한 뒤 결과와 추가 캡처를 기록해야 합니다.

## 5. 실제 실행 검증 체크리스트

아래 항목은 [기획서.md](./기획서.md)의 완성 기준 1~10번을 그대로 참조하는 **검증용 체크리스트**입니다. 실행 여부를 확인하기 전에는 완료 표시를 하지 않습니다.

- [ ] 1. 영화 검색 결과에서 포스터와 제목을 보고 목록에 추가
- [ ] 2. 카드를 드래그해 S/A/B/C/D 등급 간 이동
- [ ] 3. 같은 브라우저에서 파일을 다시 열어 영화와 등급 유지 확인
- [ ] 4. 등급표 PNG 이미지 저장
- [ ] 5. JSON 파일 저장 후 불러오기
- [ ] 6. 로그인·서버 실행 없이 HTML 파일 열기
- [ ] 7. 좁은 화면에서 내용이 잘리지 않는지 확인
- [ ] 8. 빈 제목이나 공백만 검색할 때 안내 표시
- [ ] 9. 책갈피 여러 개 생성 후 각 영화·등급 독립 관리 확인
- [ ] 10. 현재 책갈피/전체 책갈피 저장 중 선택 확인

검증이 끝나면 확인한 날짜·브라우저·결과를 추가하고 필요한 실행 화면을 사진원본 폴더에 보관할 수 있습니다.
