## 6. 제출 자료로 확인된 범위와 추가 증거가 필요한 부분

- **직접 확인 가능한 화면:** 영화 검색 결과·추가, 등급별 포스터 배치, PNG 저장 대화상자, JSON 불러오기 방식 선택, 로컬 HTML 실행, 좁은 창 배치, 빈 검색 안내, 복수 책갈피, 현재/전체 저장 선택.
- **사진만으로 과정 전체를 판단하기 어려운 항목:** 3번(재실행 전후 동일 데이터), 4번(PNG 파일 저장 완료), 5번(JSON 불러오기 뒤 데이터 복원), 9번(책갈피 전환 전후 독립 유지), 10번(두 종류의 JSON 파일 저장 완료).
- **추가하면 좋은 증거:** 재실행 전후 비교 화면, 내려받은 PNG·JSON 파일 목록, 불러오기 완료 후 영화 배치, 서로 다른 책갈피를 전환한 전후 화면. 제출한 내용 중 이미 확인한 과정은 해당 사실과 날짜를 문서에 추가할 수 있습니다.

> **제출 원칙:** 위 10장은 사용자가 실제 실행 검증 자료로 제공한 원본입니다. 스크린샷 외의 결과나 브라우저 테스트를 AI가 대신 수행했다고 적지 않았습니다. 기능의 최종 합격 판정은 제출한 자료와 직접 조작 결과를 함께 확인해야 합니다.
