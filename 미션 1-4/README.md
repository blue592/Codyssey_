# 미션 1-4 — 기능을 추가하고 원본 보존하기

영화 티어리스트에 **제목을 지정해 여러 책갈피를 만들고, 책갈피마다 영화와 등급을 관리하는 기능**을 더한 미션입니다. 기획서의 9번(책갈피별 독립 관리)과 10번(현재/전체 책갈피 저장 선택)을 추가·수정하여 HTML에 반영했습니다. 파일 저장·불러오기 방식도 개선했으며 **기능 추가 전 원본, 1차 파일, 최종 수정본을 각각 구분해 보관**합니다.

**원본 확인:** 이 폴더에 추가한 `영화_원본.html`은 [미션 1-2의 영화_수정1.html](../미션%201-2/영화_수정1.html)과 Git Blob SHA가 일치하는 동일 내용의 파일입니다. 기능 추가 이전 상태를 보존하기 위해 별도 이름으로 제출합니다.

## 확인 자료와 복구 절차

- 대화 스크린샷 3장과 완성 기준 1~10번 실제검증 화면 10장 및 확인 범위: [대화캡쳐 및 실제검증 자료.md](./%EB%8C%80%ED%99%94%EC%BA%A1%EC%B3%90%20%EB%B0%8F%20%EC%8B%A4%EC%A0%9C%EA%B2%80%EC%A6%9D%20%EC%9E%90%EB%A3%8C.md)
- 기능 추가·수정 이유와 파일별 과정: [미션4_기록.md](./미션4_기록.md)
- 원래 기능과 새 기능의 검증 기준: [기획서.md](./기획서.md)의 1~10번

원래 되던 기능이 망가진 경우의 안전한 절차:

1. **수정 중단:** 문제가 생긴 HTML을 계속 덮어쓰거나 반복 수정하지 않고 해당 파일을 보존합니다.
2. **데이터 백업:** 현재 영화 기록이 중요하다면 먼저 JSON으로 백업합니다. 브라우저 저장 데이터를 임의로 삭제하지 않습니다.
3. **원본 복구:** 변경하지 않은 `영화_원본.html`을 다시 열어 기존 기능을 확인합니다. 원본은 수정하지 않습니다.
4. **새 대화에서 재요청:** 새 AI 대화를 시작해 `영화_원본.html`과 `기획서.md`를 첨부하고 기능 추가를 다시 요청합니다. 새 결과는 별도 HTML 파일명으로 저장합니다.
5. **완성 기준 재확인:** 기획서의 1~10번을 처음부터 검사하고 원본·1차·수정본을 모두 보관합니다.

이 절차는 **문제 발생 시 대응 방법**입니다. 실제로 원본 복구를 수행했다는 의미가 아니며, 원래 기능이 손상되지 않았다면 해당 단계는 건너뜁니다.

## 두 HTML의 차이

| 비교 항목 | 1차 `영화_기능추가1.html` | 수정 `영화_기능추가수정1.html` |
|---|---|---|
| 여러 책갈피·등급 관리 | 추가한 기능 | 유지하며 수정 |
| 파일 저장 범위 | 전체 책갈피 저장 중심 | **현재 책갈피 / 전체 책갈피** 중 선택 |
| 불러오기 | 선택 방식에 부족한 점 기록 | **저장 후 불러오기 / 그냥 불러오기 / 책갈피로 불러오기** 안내 |
| 파일명 구분 | 저장 날짜 정보가 부족하다고 기록 | 날짜와 책갈피 이름을 넣도록 개선 |

구체적인 수정 요청과 결과는 [미션4_기록.md](./미션4_기록.md)를 기준으로 읽습니다. 이 README는 파일들의 역할을 설명하며 새로운 실행 검증을 했다는 뜻은 아닙니다.

**실행 방법:** 최종 결과물을 사용하려면 `영화_기능추가수정1.html`을 내려받아 브라우저에서 엽니다. 검색·온라인 포스터 표시에는 인터넷 연결과 개인 TMDB API 키 설정이 필요할 수 있습니다. 중요 데이터는 JSON 파일로 별도 백업하세요.

> 기능을 추가한 1차 HTML과 최종 수정 HTML을 혼동하지 마세요. 이전 원본 및 다른 미션 파일은 수정하지 않고 보존합니다.
