---

### 세부 기획 확정 내용

| 항목 | 결정 사항 |
|------|-----------|
| 사용 대상 | 개인 사용 |
| 목적 | 본 영화 등급 정리 |
| 티어 구성 | S / A / B / C / D (피라미드형) |
| 색상 테마 | 위로 갈수록 밝은 노랑 → 아래로 진한 노랑 (같은 계열) |
| 영화 검색 | 제목 입력 → TMDB API 포스터 자동 표시 |
| 카드 기능 | 등급 변경, 제목/포스터 수정, 드래그 앤 드롭 |
| 장르 표시 | 장르별 포스터 테두리 자동 컬러 배정 |
| 저장 방식 | localStorage 자동저장 + 파일 저장/불러오기 + 이미지 다운로드 |
| 기술 스택 | HTML / CSS / JavaScript 단일 파일 |
| 화면 대응 | 반응형 (모바일 포함) |
| API 키 입력 | 웹페이지 설정 화면에서 사용자 직접 입력 |
| API 키 보안 | 저장 파일·HTML 코드 미포함, localStorage에만 저장 |
| 언어 | 화면 문구 한국어 |

## 💻 개발 단계

### 사용자 요청

> 이 기획서대로 HTML·CSS·JavaScript가 모두 들어 있는 HTML 파일 하나를 만들어 줘.  
> 외부 파일이나 서버 없이 브라우저에서 바로 열리게 하고, 화면 문구는 한국어로 써 줘.  
> 완성된 .html 파일로 제공해 줘.

### AI 응답

> 바로 만들어드릴게요! 🚀

### 코드 작성 시도 1차

- HTML/CSS/JS 단일 파일 작성 시작
- **문제 발생**: 코드가 중간에 잘려서 미완성 상태로 출력됨

```
/* 반응형 */

```

### 코드 작성 시도 2차

- 처음부터 전체 재작성 시도
- **문제 발생**: 동일하게 코드가 중간에 잘림

```

```
